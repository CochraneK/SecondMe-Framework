# 个人生活专题地图｜Personal Domains v0.3

> **每个人都可以使用同一套资料分类能力，但无需拥有相同经历、偏好或结论。**
> 这是一套可选的**资料目录（collections）**，不是新增的人格因子、心理测验或必填问卷。
> 唯一上位本体仍是 [12 维 Human Ontology](human_ontology.md)。

## 两层分类，不重复创造本体

1. **Ontology / 如何理解**：12 个基础维度，如认知、关系、价值、时间中的自我。用来整理问题、选择理论，不产生强制量表分数。
2. **Personal domains / 保存什么**：具体的生活主题，如欣赏人物、书影音、决策、梦境、游历、创作。它们是多对多的资料集合，不声称彼此正交。

一条记录可以在多个专题索引中被引用，但**内容只有一个 canonical 文件**，避免重复粘贴、版本分叉。

## 三个不应误作个人特质的治理层

| 横跨所有专题 | 做什么 | 入口 |
|---|---|---|
| Evidence | 出处、证据类型、反例、置信度、时间、匿名化 | [证据协议](evidence_protocol.md) |
| Decision log | 选择与结果；**Idea、建议和最终决定必须分开** | [决策模板](../templates/DECISION_TEMPLATE.md) |
| Model update | 随新事实修订解释、降权、反驳或退休 | [模型更新](model_update.md) |

Evidence / governance 不是 D21 或“人的隐藏维度”。

## 每个人都可以有，不代表每个人都得填

新用户会从模板获得**同一份 20 类专题导航**、官方空白模板和可选的对话提示。它们允许四种状态：

- `EMPTY`：没记录，不代表这个人没有该主题。
- `DECLINED`：本人选择不谈、不保存或撤回。
- `IN_PROGRESS`：只有零散事实和待核实猜想。
- `ESTABLISHED`：本人确认有一定可信依据；也仍可修订。

绝不把 `EMPTY` 自动解读为“不喜欢读书”“没有亲密关系”“没有梦想”或“人格维度缺失”。

## 尤其要区分的四种人物记录

- **喜欢 / 欣赏**：本人明确表达过喜欢或欣赏谁；理由可未知。
- **认同**：本人明确表示认可对方的某个具体观点或行为；不等于赞成全部。
- **相似性**：仅是可反驳的比较；不是客观人格分类或成就等同。
- **历史关系**：真实互动与对方意图分别标注；他人的思想、动机与私人身份不能由模型猜填。

对虚构角色、小说与梦境的记录，也不允许自动推断使用者在现实中具有相同意图或道德立场。

## 推荐给刚开始使用的人的轻量方法

1. 打开 [个人专题导航模板](../templates/DOMAIN_INDEX_TEMPLATE.md)，**复制到自己的 Private 仓库** `my/INDEX.md`；原模板保留完整 20 类，自己的副本可自由删改。
2. 先从最想聊的**一个**专题开始，例如“喜欢的角色”“最近一次重要决定”“某首歌为什么重要”。
3. 需要时复制对应空白模板到 `my/`，不直接在 `templates/` 原件填写。
4. 累积事实后，再通过 [12 维本体](human_ontology.md) 与 [方法选择器](method_router.md) 判断是否值得形成个人工作模型。
5. 不愿意使用 Git 时，也可把同样的空白模板保存在自己的本地文件夹。

**没有软件能在未获得资料的情况下，自动生成真实的人生档案。维度是容器，内容来自本人。**
