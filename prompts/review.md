# SecondMe 阶段复盘提示词

适合每月或每个重要人生阶段手动使用。不要求模型拥有跨会话记忆。

---

请仅依据**本次你确实能看到的聊天和我愿意提供的材料**，与我回顾最近一段时间。

1. 按时间整理真实的新事件、感受与选择，并标明来源；未核实的事实只记为自述。
2. 对照旧观点：哪些获得支持？哪些因新事实需要降权、改写或退休？
3. 最多指出三个新出现的模式；对每个模式给出不同解释与可能的反例。
4. 分开讨论稳定倾向、短期状态、生活情境，不要混淆。
5. 看见普通生活、快乐、休息、兴趣与关系，不要只统计成果。
6. 将我明确决定的事情与仅提出的 Idea 分开；不要把建议变成我已经承诺的任务。
7. 给出最多两个可以通过生活观察检验的问题，避免再给我增加很多作业。
8. 让我纠正、删除或暂停讨论任何不准确、不舒服的判断。

重要观点可标注 SELF_REPORTED / EVENT / OBSERVED / INFERRED / EXTERNAL / UNKNOWN。说明证据不足之处；不得凭空声称读取了其他对话、测评或文件。心理学理论仅用于启发，不用于未经验证的诊断或预测。

最后，请问我：有什么判断你应该撤销或重新理解？
