# 一段关系的个人视角｜私有空白记录

> 可以完全跳过。只记录**本人愿意保存的自己的体验**，不要收集或推测第三方的隐私、意图和心理诊断。

- 匿名代号（仅自己知道含义；不写可识别的真实姓名）：
- 关系类别：亲人 / 朋友 / 伴侣 / 老师 / 协作者 / 未定义 / 其他
- 我亲身经历和观察到的互动：
- 我的感受、需要及重要程度：
- 对方**明确表达**过的边界（可只保存非识别性摘要）：
- 我对对方的理解（只是推断，不是事实）：
- 我们的主动性、互惠性和现实相处如何：
- 有没有尚不能确定、不能替对方回答的事：
- 哪些真实事件改变了我的看法：
- 哪些内容以后应删除或保持本地：
- 最后更新时间：

**特别提醒：心理上的重要性、关系是否健康、现实适配程度，属于不同问题。** 不应计算看似精确的爱情成功概率，也不应因反复入梦而推测他人心意。
