# 喜欢、不喜欢与审美｜空白记录

> 这些体验可以完全没有“成长价值”，不必通过人格理论解释。

- 对象：食物 / 活动 / 声音 / 风景 / 角色 / 颜色 / 书影音 / 其他
- 我喜欢／不喜欢／矛盾／说不清：
- 本人原话或自愿描述：
- 我为何喜欢（未知也可以）：
- 哪些情境会改变这种感受：
- 何时开始、是否变化过：
- 我希望这成为私密收藏，还是愿意用于一般性自我了解：
- 来源：SELF_REPORTED / EVENT / OBSERVED / INFERRED / UNKNOWN
- 暂不形成的推断（例如“喜欢某题材所以一定有某种人格”）：

**没有明确证据，就不要替人推断喜爱理由。**
