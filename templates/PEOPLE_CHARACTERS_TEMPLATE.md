# 喜欢的人 / 虚构角色 / 比较参照｜空白卡

> 用于本人自愿记录**欣赏的人物或角色**。请在私人空间保存，不提供真实第三方的秘密、地址、联系方式或聊天原文。

- 本人使用的称呼／公开角色名：
- 类型：现实学者 / 老师或领导 / 公众人物 / 虚构角色 / 相似人物候选 / 其他
- 来源（作品、公开资料或本人回忆，不需私人身份）：
- 最初接触的时间或阶段（可留空）：
- 我是否明确说过喜欢／欣赏？SELF_REPORTED / UNKNOWN：
- **我明确喜欢的具体方面**（如果没说过，写 UNKNOWN）：
- 我认同的观点或行为（可留空；喜欢不等于赞同）：
- 我不认同或持保留意见的方面（可留空）：
- 与我有何相似（仅候选推断，不等于身份、能力或成就）：
- 更像自我镜像 / 理想镜像 / 警示镜像 / 情感锚点 / 纯粹喜爱？
- 证据来源、可能的反例和待本人确认之处：
- 更新时间／是否仍认同：

**四件事不能混为一谈：喜欢、认同、相似、想成为。**

仅凭某人是我最喜欢的角色，不得断言我具有他的动机或行为；仅凭欣赏一位老师，不得编造他为什么值得欣赏。
