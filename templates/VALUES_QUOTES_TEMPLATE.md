# 价值观、个人原则与喜欢的句子｜空白模板

> 只在本人确认时，将一个观点记为其个人价值。别人的思想和 AI 提议不自动成为本人的信念。

## 一条价值观
- 名称：
- 本人认可的具体表述（如为 AI 总结，明确注明）：
- 曾体现这一价值的真实行为或选择：
- 什么情境下可能不适用：
- 有什么相反证据：
- 目前状态：本人明确认可 / 候选推断 / 不确定
- 是否愿意付出代价，以及代价范围（可留空）：

## 一句我想保存的话
- 句子：
- **真实作者或来源**：本人原句 / 共同创作 / AI 蒸馏 / 外部作者 / 来源待核
- 原始作品、许可或引文来源（如果有）：
- 是我明确喜欢，还是 AI 推荐的候选：
- 我为什么收藏（未知可留空）：
- 日期与可能变化：

**不要把“引用过”升级成“认同”；不要把 AI 写的句子伪称为本人原创。**
