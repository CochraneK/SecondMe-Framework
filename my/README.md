# my/｜这里存放自己的记录（模板说明）

> 这个文件只是**空白说明**。从公开模板创建私人仓库后，这里才用于记录属于你自己的内容。

**开始前先确认仓库是 Private。** 不需要填写所有维度，也不要把别人的真实经历直接放进来。

## 已为新用户提供的 20 类可选生活专题

直接打开 [my/INDEX.md](INDEX.md) 查看从身份、欣赏人物与角色、价值、关系，到决策、旅行、音乐、阅读、创作、梦境、快乐与阶段复盘的 20 类空白索引。

它只是「可以保存什么」的完整地图，**不要求每个人都拥有全部内容，也不预设任何人格结论**。正式的官方分类规则见 [Personal Domains](../framework/personal_domains.md)。

如果你此前用旧版模板建立了仓库，上游更新**不会覆盖**你现有的 `my/`。请主动从 [DOMAIN_INDEX_TEMPLATE](../templates/DOMAIN_INDEX_TEMPLATE.md) 复制或合并到自己的索引。

## 推荐的最简结构

```text
my/
├── README.md       使用提示（当前文件）
├── INDEX.md        20 类可选专题的空白导航
├── self.md         对自己的阶段性理解（自己创建）
├── evidence/       具体经历与可追溯依据（按需创建）
├── reviews/        定期复盘（按需创建）
└── decisions/      重要决策与事后回顾（按需创建）
```

**如何开始：** 复制 `templates/SELF_TEMPLATE.md` 的内容到 `my/self.md`，删去不想填写的部分。首次可以只有一小段自述。

- `SELF_REPORTED`：自己明确说过、感受到、愿意确认的；
- `EVENT`：实际发生的经历；
- `INFERRED`：AI 或本人对现象做出的候选解释，不等于事实；
- `UNKNOWN`：不知道就留空。

**官方自动更新器不会读取、提交或修改 `my/`。** 但 GitHub 仓库本身仍可能将你主动提交的内容存储在云端；不要以为 Private 就等于加密。

私人第三方聊天、健康、身份标识或其他高度敏感的原始材料，优先考虑不上传，仅保留必要的最小摘要或本地存储。

**这个目录不应该被打包回公开框架，也不应该用于贡献公共教程。**
